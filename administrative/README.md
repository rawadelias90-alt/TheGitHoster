# Administrative

Reusable bilingual web template for the **Administrative Services Commercial Pack**.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual styling and print rules
- `script.js` — English/Arabic switching, RTL handling, pricing calculations, draft persistence, and print actions

## Use

Open `index.html` in a browser. No build step or external framework is required.

The template supports English and Arabic, responsive desktop/mobile layouts, proposal pricing calculations, local draft saving, and browser print/PDF output.

## Reuse

Keep project-specific changes inside this folder. Additional projects can be added later as separate top-level folders in the repository using the same pattern.
